# Quince Matrix

Live SKU stock and sales dashboard for the Quince vendor portal (JDA Texworld, vendor JTPL004).

- Stock per SKU = inspected qty − pieces sold; sales are taken from the oldest inspected PO first (FIFO).
- Colour rules: red ≤ 20 pcs, yellow 21–100 pcs, green > 100 pcs.
- Updated after each day's order confirmation. Order numbers, AWB numbers and customer details are not published.

Open the dashboard: https://sunilahamed.github.io/quince-matrix/
